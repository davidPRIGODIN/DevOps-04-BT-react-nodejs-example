# DevOps-BT-react-nodejs-example

A simple JavaScript application using npm as its package manager.

## Usage
Navigate to the application directory:

```bash
cd api
```

Install the dependencies:

```bash
npm install
```

Build the application:

```bash
npm run build
```

Start the application:

```bash
npm start
```
